# Actualización con GitHub Desktop — Versión 4

1. Descomprima `Sistema_Integrado_DGA_OPP_UNT_v4.zip`.
2. En GitHub Desktop abra `sistema-integrado-gestion-dga-opp-unt`.
3. Use **Repository → Show in Explorer**.
4. Elimine/reemplace el contenido visible de la carpeta local del repositorio con el contenido de `Sistema_Integrado_DGA_OPP_UNT_v4`.
5. **No elimine la carpeta oculta `.git`** del repositorio local.
6. Regrese a GitHub Desktop.
7. Revise que se detecten los archivos nuevos/modificados.
8. Use como Summary:

   `Versión 4 - interacción integral, mesa documental e inteligencia presupuestaria`

9. Pulse **Commit to main**.
10. Pulse **Push origin**.
11. Espere el despliegue de GitHub Pages.

## Recorrido recomendado después de actualizar

1. **Administrador General → Panel ejecutivo**.
2. Haga clic en una tarjeta o gráfico y navegue hasta su detalle.
3. **Organización → DGA/OPP → unidad → área/subárea → responsable → servidor**.
4. Abra un servidor y pruebe **Metas**, **Asistencia**, **Documentos** y **Agenda**.
5. En **Documentos y SGDUNT**, cree un documento, edítelo, guárdelo, descargue Word, imprima/PDF y recorra revisión/firma/derivación.
6. En **Presupuesto**, abra un centro de costo y revise líneas económicas, POI, obligaciones y margen evaluable.
7. En **Laboratorio financiero**, indique destino y monto; seleccione un origen y observe el antes/después.
8. En **Inversiones**, abra un proyecto y navegue a una alternativa de financiamiento.
9. Maximice una tarjeta con **⛶**.
10. Abra el asistente y pregunte:

   - `¿Qué debería preocuparme hoy y llévame a revisarlo?`
   - `Necesito S/ 0.5 millones para una inversión prioritaria. ¿De dónde conviene obtenerlos y qué afectaría?`
   - `¿Cómo va la ejecución presupuestal del centro 1.10.06?`
   - `¿Por qué el saldo PIM menos devengado no es dinero libre?`
   - `¿Qué documentos requieren firma o revisión?`
   - `¿Quién presenta más tardanzas dentro de Recursos Humanos?`
   - `Llévame a ello.`

11. Use **Visualizar dashboard** desde una respuesta del asistente.
12. Pruebe **Ctrl + K** para búsqueda/comandos globales.
