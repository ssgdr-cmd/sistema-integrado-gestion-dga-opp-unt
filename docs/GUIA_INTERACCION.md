# Guía de interacción v4

## Director / Administrador

- Panel ejecutivo → clic en KPI → detalle.
- Organización → unidad → área → subárea → responsable → servidor.
- Presupuesto → centro de costo → desglose → POI → alternativas.
- Inversiones → proyecto → avance físico-financiero → brecha → laboratorio.
- Asistencia → unidad/persona → calendario → día.
- Reportes → ejecutivo / presupuesto / asistencia / GdR / inversión / contratación / documentos.

## Jefatura / responsable

- visualizar equipo del ámbito;
- asistencia y permanencia;
- tareas y Gantt;
- documentos y pendientes;
- centro de costo del ámbito cuando exista;
- productos GdR;
- alertas y reportes.

## Servidor

- mesa de trabajo;
- tareas/metas;
- asistencia diaria;
- agenda;
- crear/editar documento;
- descargar Word;
- imprimir/PDF;
- enviar a revisión;
- solicitar firma;
- preparar registro/derivación;
- reportes propios.
