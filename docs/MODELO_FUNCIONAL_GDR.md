# Modelo funcional construido desde GdR DGA–OPP UNT 2026

La aplicación utiliza el archivo entregado para el proyecto `FORMATOS GDR DGA OPP UNT 2026.zip` como fuente funcional primaria para construir la capa de personas y responsabilidades.

## Cobertura procesada

- 31 libros de Gestión del Rendimiento.
- 124 registros evaluados válidos dentro de la relación DGA–OPP y registros vinculados.
- 127 personas en el grafo al incorporar responsables/evaluadores que no cuentan con ficha individual dentro de un libro específico.
- 33 nodos organizacionales principales DGA–OPP.
- Todos los nodos organizacionales del árbol principal tienen un responsable asociado.

## Cómo se determina la jerarquía

Se utiliza la relación:

`servidor evaluado → evaluador → unidad del evaluador`

para identificar responsables funcionales, sin exponer DNI.

La estructura organizacional principal aplicada es:

- Dirección General de Administración
  - Unidad de Abastecimiento
    - Área de Almacén General
    - Área de Control Patrimonial
  - Unidad de Tesorería
    - Área de Gestión de Ingresos
    - Área de Gestión de Egresos
  - Unidad de Contabilidad
    - Área de Control y Devengado
    - Área de Integración Contable
  - Unidad Ejecutora de Inversiones
  - Unidad de Servicios Generales
    - Área de Transportes
    - Área de Talleres
    - Área de Limpieza y Mantenimiento
    - Área de Áreas Verdes y Jardinería
  - Unidad de Recursos Humanos
    - Área de Escalafón
    - Área de Capacitación y Gestión del Talento Humano
    - Área de Remuneraciones y Pensiones
      - Subárea de Pensiones
    - Área de Personal Académico
      - Subárea de Control Docente
    - Área de Personal Administrativo
      - Subárea de Control Administrativo
    - Área de Seguridad y Salud en el Trabajo
    - Secretaría Técnica de Procesos Administrativos Disciplinarios
- Oficina de Planeamiento y Presupuesto
  - Unidad de Planeamiento
  - Unidad de Presupuesto
  - Unidad de Desarrollo Organizacional y Modernización
  - Unidad de Estadística
  - Unidad Formuladora de Proyectos

## Regla de interpretación

Una meta GdR se utiliza como evidencia de un producto o responsabilidad observable. No se asume que represente la totalidad de las funciones del puesto.

La aplicación distingue:

1. dato expresamente contenido en GdR;
2. relación jerárquica evaluador–evaluado;
3. información operativa generada para permitir interacción y simulación.

## Privacidad

No se incluyen DNI, cuentas bancarias, teléfonos personales, diagnósticos de salud ni contenido reservado de procedimientos disciplinarios.
